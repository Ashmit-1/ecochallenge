# versions/

Ordered migration scripts. **Never edit an applied migration** — add a new one instead.

| Revision | Description |
|---|---|
| `f3f9b1b53a8a` | Initial schema: `users`, `challenges`, `submissions` + indexes |

The revision id is generated by Alembic; the filename prefix is that id. Keep the generated
`down_revision` chain intact — `alembic upgrade head` follows it from the base.

## Generating the next one

```bash
uv run alembic revision --autogenerate -m "short description"
```

Then open the file and check it before running anything:

1. Add `import sqlmodel` if column types reference `sqlmodel.sql.sqltypes`.
2. Confirm only the tables/columns you actually changed appear.
3. Add data backfills explicitly.
4. Run `uv run alembic upgrade head` against a **copy** of the dev database first if the change is
   destructive.

See [../alembic.md](../alembic.md) for the full checklist.
