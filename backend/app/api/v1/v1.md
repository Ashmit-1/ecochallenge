# v1/

Version 1 of the HTTP API, mounted at `/api/v1` by [main.py](../../main.py).

| File | Purpose |
|---|---|
| [router.py](router.py) | Assembles all route modules — the one place to add a new router |
| [routes/](routes/routes.md) | One module per resource: auth, challenges, submissions, profile, leaderboard, system |

OpenAPI docs are generated automatically at `/docs`, and `/redoc` is disabled.

Adding an endpoint: create/extend the route module, include it in `router.py` if it is a new module,
then update [docs/api.md](../../../../docs/api.md).

Trailing slashes: collection routes are registered at the empty path (`""`), so the canonical URL
is `/api/v1/challenges`, not `/api/v1/challenges/`.
